# ExpBot

**报销文件批处理工具** —— 把散落的发票、订单、支付截图，整理成可提交的标准 PDF 材料包。

报销准备常常很繁琐：多笔采购混在一起、长截图要拼接、发票要带留白打印、每笔还要单独建文件夹……ExpBot 在本地把这些步骤串起来，尽量一次做完。

## 它解决什么

| 以前 | 现在 |
|------|------|
| 自己分类发票 / 订单 / 支付 | 视觉模型按图归组 |
| 长图手动裁切拼接 | 本地像素拼接 + 去无用边框 |
| Word/PS 排版凭证 | 一键横向 A4 凭证 + 发票打印版 |
| 一笔一个文件夹、两份 PDF 手搓 | 自动命名并导出 |

本机运行。材料默认不离开你的电脑；只有你点击整理 / 制作时，才会把**当次需要的图**发给你自己配置的 OpenAI 兼容视觉接口。

## 原理（很短）

```
导入图片/PDF
    ↓
视觉模型分批看图（每轮最多 8 张）
  · 分类：发票 / 订单 / 支付 / 无关
  · 归组：同一笔采购
  · 轻量核对：抬头税号、地址、缺材料、是否模糊
    ↓
本地排版（Pillow + 内置 pypdf）
  · 订单+支付 → 横向 A4「购买及支付凭证」
  · 发票 → 带留白的「电子发票打印版」
    ↓
每笔采购一个文件夹，恰好 2 个 PDF
```

- **原件只读**：分析与裁切都在副本上，原始文件与哈希保留。
- **无聊天纠错框**：后台提示词固定，界面是向导式批次。
- **机构信息自填**：发票抬头、税号、统一收货地址等在「设置」里填写，仓库不绑定任何单位。
- **密钥本机加密**：Windows DPAPI；发布包不含密钥。

## 快速开始

### 发行包（推荐）

1. 在 [Releases](../../releases) 下载  
   - **便携版** `ExpBot-v1.0-Windows.zip`：解压后双击 `ExpBot.exe`  
   - **安装版** `ExpBot-v1.0-Setup.exe`：免管理员，装到当前用户目录  
2. 打开「设置」填写：  
   - 姓名 / 导师 / 项目 / 输出目录  
   - **发票抬头、税号、统一收货地址**（可选：地址关键词、开户行等）  
   - 视觉 API 地址 / 模型 / Key  
3. 「开始」→ 拖入材料 → 整理 → 制作 → 导出。

需要系统已安装 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)（Win10/11 通常已有）。

### 从源码运行

```powershell
pip install pillow
python run.py
python -m unittest discover -s tests -q
```

前端为本地 HTML/CSS/JS，无 npm 构建。
